### ปัญหาสุดท้าทาย: ค่า Confidence Score ต่ำ

ค่า Confidence Score นั้นคือค่าที่บ่งบอกว่าการแยกแยะของวัตถุนั้นสามารถน่าเชื่อถือหรือแม่นยำได้มากขนาดไหน แต่สิ่งที่เกิดขึ้นเมื่อเราได้เริ่มกดเทรนและทดลองใช้ในรอบแรกนั้น ค่า Confidence Score นั้นต่ำอย่างน่าใจหาย AI ไม่สามารถแยกแยะสิ่งของจากรูปที่พวกเราได้ถ่ายกันไว้เท่าที่พวกเราได้คาดหวังกัน ซึ่งพวกเราก็ได้ทำการ Brain Storming จนได้รู้สาเหตุที่รูปภาพที่เราได้ถ่ายไว้ถึงใช้งานจริงไม่ได้

1. คุณภาพรูปที่ใช้เทรน
   - รูปที่ใช้งานนั้นมีสิ่งแวดล้อมมากเกินไป มีพื้นหลังที่ทำให้ AI เข้าใจว่าสิ่งนั้นคือวัตถุเช่นกัน
   - รูปที่มีนั้นมีมุมกล้องที่ไม่หลากหลาย ทำให้ AI ไม่สามารถวิเคราะห์วัตถุจากมุมหรือด้านที่ไม่เคยได้รับข้อมูลมาก่อนได้
   - แสงสว่างไม่มากพอ รูปที่ใช้ถ้ามีความมืดไป จะทำให้ไม่เห็นรูปร่างหน้าตาวัตถุได้อย่างชัดเจน
   - แสงสว่างในแต่ละรูปไม่เท่ากัน ทำเกิดการวิเคราะห์ที่ผิดเพี้ยน
   - ข้อมูลที่ใช้เทรนไม่เพียงพอ
2. สิ่งแวดล้อมขณะใช้งาน
   - หากขณะที่ใช้งาน สิ่งแวดล้อมมืดเกินไปก็จะทำให้เกิดการวิเคราะห์ที่ผิดเพี้ยน
   - หากในขณะที่ใช้งาน พื้นหลังนั้นมีความวุ่นวาย (เช่นอยู๋ในที่ที่มีสีเยอะๆ วัตถุอยู่ด้านหลังมากๆ) ก็จะทำให้วิเคราะห์ข้อมูลได้ผิดเพี้ยนเช่นกัน
  
เมื่อช่วยกันวิเคราะห์จนทราบถึงสาเหตุทั้งหมด จึงเริ่มทำการทดลองใหม่และหาวิธีแก้ไข้ปัญหาทันที เพื่อที่ว่าปัญหาจะไม่ค้างคานานจนเกินไป โดยวิธีแก้ไขของพวกเรานั้นก็สามารถทำให้ค่า Confidence Score ขึ้นมาสูงแตะ 100% ได้ 

### 📏 วิธีการแก้ไขปัญหา

1. เพิ่ม Dataset - ถ่ายรูปเพิ่มอีกหลายๆ มุมและระยะ ทั้งใกล้และไกล เพื่อให้ AI เรียนรูปทรงที่แท้จริง
2. ปรับแสงสว่าง - ทุกคนในทีมเปิดไฟฉายบนมือถือเพื่อเพิ่มแสงสว่างขณะถ่ายรูป
3. เปลี่ยนมุมกล้อง - ปรับมุมกล้องให้หลากหลายมากขึ้น เพื่อให้ได้มุมมองที่แตกต่างกัน
4. เทรนโมเดลใหม่ - หลังจากปรับปรุงข้อมูลแล้ว กด Train Model ใหม่อีกรอบ
5. ทำงานเป็นทีม - ทุกคนร่วมมือกันและช่วยเหลือซึ่งกันและกันในการแก้ปัญหา
6. ใช้แหล่งข้อมูลจากภายนอกเพิ่มเติม - เพิ่มรูปภาพจากแหล่งภายนอกเพิ่มเติมเพื่อให้ข้อมูลที่ได้รับมีคุณภาพมากขึ้น
